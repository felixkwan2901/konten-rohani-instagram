# Font pengganti untuk render di cloud

Semua file `.ttf` di folder ini diunduh dari Google Fonts oleh `ambil_font.py` dan berlisensi
SIL Open Font License 1.1 atau Apache License 2.0, jadi boleh disimpan dan dibagikan di repo publik.
Font ini hanya dipakai kalau font macOS tidak ada (mesin Linux di cloud) atau kalau `FONT_CLOUD=1`.
Peta macOS → pengganti ada di `fonta.py`.
